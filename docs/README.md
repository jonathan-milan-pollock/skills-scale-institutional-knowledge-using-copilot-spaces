# OctoAcme Project Management Docs

This folder contains the official process documentation for OctoAcme's project management framework.

## Overview

OctoAcme follows a structured, iterative project management approach built around five core principles:

- **Customer-first** – prioritize customer value and usability in every decision.
- **Iterative delivery** – ship small, testable increments to learn and adapt quickly.
- **Clear ownership** – each project has a named Project Manager (PM) and Product Lead accountable for outcomes.
- **Data-informed decisions** – measure impact and iterate based on evidence rather than assumption.
- **Psychological safety** – encourage open feedback and continuous learning across all roles.

Projects move through a defined lifecycle: **Initiation → Planning → Execution → Release → Retrospective**. Cross-functional teams—including Project Managers, Product Managers, Developers, and QA—collaborate using a shared set of artifacts (project charter, roadmap, sprint backlog, risk register, and retrospective notes) to keep work visible and aligned.
